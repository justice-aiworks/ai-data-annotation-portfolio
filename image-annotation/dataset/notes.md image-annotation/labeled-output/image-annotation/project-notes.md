# Traffic Image Bounding Box Annotation Project

## 🎯 Objective
The goal of this project was to annotate a traffic scene image dataset using bounding box labeling. The purpose is to prepare high-quality training data for computer vision object detection models.

---

## 📊 Dataset Description
The dataset consists of real-world traffic scene images containing multiple objects commonly found on roads, including vehicles and pedestrians.

---

## 🏷️ Labels Used
The following object classes were identified and annotated:

- Car
- Pedestrian
- Truck
- Two-Wheeler (Motorcycles/Bikes)
- Auto (Tricycle/Three-Wheeler)

---

## 🧰 Tools Used
- Label Studio (for bounding box annotation)
- GitHub (for project hosting and version control)

---

## 🖼️ Annotation Method
- Each image was reviewed manually
- Bounding boxes were drawn around each object
- Each object was assigned a correct label category
- Care was taken to ensure accuracy and consistency across all annotations

---

## 📦 Output
The final output includes:
- Annotated images with bounding boxes
- Exported dataset in Label Studio format (JSON/CSV)
- Organized dataset ready for machine learning model training

---

## 🚀 Outcome
A structured and labeled traffic dataset suitable for training object detection models in computer vision applications such as traffic monitoring and autonomous systems.
